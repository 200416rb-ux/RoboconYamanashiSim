# RoboconYamanashiSim
Unityプロジェクトにおけるロボコンやまなしフィールドの制作。

## フィールドを開く

- `Assets/Scenes/Field1.unity`：既存フィールド。ホール位置の変更に対応。
- `Assets/Scenes/Field2.unity`：添付の寸法図を基にしたL字フィールド。

Projectウィンドウから対象シーンをダブルクリックしてください。通常は1つのフィールドだけを開きます。

## ホール位置の変更（両フィールド共通）

1. 再生を停止し、Hierarchyで `FieldRoot > HoleRoot` を選択します。
2. Inspectorの `Movable Golf Hole > Position XZ` を変更します。単位は **m**、Xは横方向、Y欄は地面の **Z方向**です。
3. またはSceneビューの移動ツール（W）で、HoleRootをX/Z方向にドラッグします。
4. Ctrl+Sでシーンを保存します。再生中の変更は再生終了時に戻ります。

旗・ビーコン・LED・カップ底・内壁、グリーンの開口とTerrainの当たり判定が連動します。グリーンの外形は変わりません。直径130mmのカップ全体がグリーン内に収まる位置だけを受け付け、範囲外の指定は直前の有効位置に戻します。高さは固定です。

| シーン | 初期Position XZ | 座標系 |
| --- | --- | --- |
| Field1 | (1.2, 0.05) | 既存Unityワールド座標を維持 |
| Field2 | (2.7, 0.9) | 添付図の(0,0)がUnityのX=0、Z=0。図のmmを1000で割る |

## フィールド２の寸法と前提

- 全長3.6m、右側区画1.8m×1.8m、左側通路の幅0.9m。
- スタート中心(-0.25, 0.45)、ティー中心(0.25, 0.45)、グリーン中心(2.7, 0.9)。座標はX/Z、単位m。
- 既存モデルに合わせ、地面高さは約0.30m。ロボットとボール、ホール一式をField1から引き継いでいます。
- フェアウェイ境界、角の丸み、グリーンの幅・奥行きは添付図の比率からの近似です。材質の色・摩擦等は実物の再現精度を保証するものではありません。
- 参照先：<https://junkshop.mesa.yamanashi.ac.jp/robocon/rule/univ/univ_2026.htm>。実装時は502エラーで本文を取得できなかったため、添付図を形状の基準としています。

## 実装と検証

`MovableGolfHole` は元のグリーンメッシュから円形の開口を再生成し、TerrainDataのコピーに穴を開けます。元アセットは変更しません。保存時は元アセットへの参照を保存し、読込時に開口を復元します。

Unity CLIで `unity command eval_file GolfFieldValidation.cs` を実行すると、両フィールドのホール移動、元の穴の復元、移動先の開口、境界制約、Transform移動、保存・再読込を検証できます。この検証はシーンを保存・開閉し、終了時にField2を開きます。未保存の作業がない状態で実行してください。
